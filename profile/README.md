# GDG OAU Mobile Development

**Building mobile experiences. Empowering developers. Shipping ideas.**

Welcome to the mobile development community at **Google Developer Groups on Campus, Obafemi Awolowo University (GDG OAU)**.

We're a community of developers passionate about building mobile applications, exploring new technologies, and learning together. Whether you're just starting your mobile development journey or already building production-ready applications, there's a place for you here.

## What We're About

- **Mobile Development:** Explore Flutter, React Native, Kotlin, Java, and native Android development.
- **AI-Powered Development:** Learn how to leverage AI tools to build, improve, and ship mobile applications.
- **Hands-on Projects:** Turn ideas into real applications through practical projects and collaboration.
- **Learning Together:** Share knowledge, ask questions, and grow alongside other developers.
- **From Code to Play Store:** Learn how to build, test, sign, and publish Android applications.
- **Open Source:** Collaborate on projects, contribute to repositories, and build your developer portfolio.

## Technologies

Our community welcomes developers working with different tools and technologies.

| Category | Technologies |
|---|---|
| Cross-platform | Flutter, React Native |
| Native Android | Kotlin, Java |
| Languages | Dart, JavaScript, TypeScript |
| AI Development | AI-assisted coding tools and APIs |
| Tools | Git, GitHub, Android Studio |

## Our Mission

To create an inclusive, hands-on learning environment where students can develop practical mobile engineering skills, collaborate on meaningful projects, and gain the confidence to build and ship applications.

## Get Involved

You don't need to be an expert to contribute. You just need the willingness to learn and build.

- Explore our repositories.
- Contribute to community projects.
- Share ideas and collaborate with other developers.
- Participate in workshops, challenges, and community activities.
- Help other developers learn and grow.

**Every great mobile developer starts somewhere. Start building with us.**
